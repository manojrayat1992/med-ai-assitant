Security & data handling

Understand the data path before you connect.

Workspace isolation, role-based access and recorded review actions are built into the application. Deployment settings and provider agreements still need review before processing patient information.

Workspace boundaries

Tenant-scoped application checks and PostgreSQL row-level security separate workspace data. User roles control available actions.

Accountable review

Report sign-off records the reviewer and time. Audit records support inspection of application actions; they are not an independent security certification.

Private source storage

Source uploads are stored and retrieved through the configured S3 service. Bucket access, encryption, region and backups must match the deployment’s requirements.

Transparent about our current stage

No independent compliance certification or medical-device clearance is claimed here. Enterprise SSO, vendor-specific integrations and contractual data arrangements must be confirmed separately.
